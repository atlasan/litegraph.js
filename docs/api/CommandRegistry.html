Class: CommandRegistry

CommandRegistry()

Named, reusable operations shared by keybindings, menus, search and extensions. A command is `{id, run(ctx), label?, category?, when?(ctx), mutatesGraph?}`. - `ctx` is a plain object, usually `{canvas, graph, event}` (see CommandRegistry#contextFor). - `when(ctx)` decides if the command applies right now; a disabled command is not run. - `mutatesGraph: true` runs the command inside `graph.transact(label, ...)`, so whatever it changes becomes one undo entry and one revision.
