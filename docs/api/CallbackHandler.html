Class: CallbackHandler

CallbackHandler()

Prioritised, vetoable hooks around the classic `onX` callbacks. Assigning `node.onExecute = fn` (or a prototype method) keeps working: it is the *default* callback of the chain. Registered handlers run by priority (highest first); the default runs after those with priority >= 0 and before the negative ones. const off = node.onHook("onExecute", (info, param) => ({ return_value: 42, result_priority: 1 }), { priority: 1 }); off(); // or node.unregisterCallbackHandler("onExecute", id) with the id registerCallbackHandler returns A handler result may be a plain value or `{return_value, result_priority, prevent_default, stop_replication}`. Hooks are synchronous (a Promise result is not awaited). A handler that throws does not stop the others: the chain completes and the first error is then rethrown to the caller. Listener storage, ordering and copy-on-write come from ListenerList (shared with typed events).
