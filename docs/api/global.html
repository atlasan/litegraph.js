(constant) ComfyInterop

Optional ComfyUI workflow interoperability. Loads ComfyUI workflow JSON (schema 0.4 and 1) into an LGraph so it can be inspected, edited and saved back without losing data this runtime does not model, and exports LGraphs as ComfyUI-shaped documents. Node types unknown to this runtime become hidden placeholder types that keep every stored field. Importing has no global effect until it is called. Mode 4 means different things: LiteGraph ON_REQUEST vs ComfyUI BYPASS. The mapping is explicit: - import: Comfy BYPASS (4) -> LiteGraph NEVER (2); the node ids are remembered in graph.extra.comfy_bypassed so export restores 4 while the node is still NEVER. - export: LiteGraph ON_REQUEST (4) -> Comfy ALWAYS (0) plus a `litegraph_mode: 4` marker that import restores. Designed after ComfyUI's documented workflow schema; no ComfyUI code is included.

(constant) PACK_ID_PATTERN

Node packs: a manifest (plain JSON) that names a group of node types, extensions and libraries, with a version and the litegraph range it needs. Manifests are data: nothing here fetches or evaluates code. A pack's code is whatever the page or the runner already imported; while it runs inside `register(manifest, setup)` (or between `open` and `close`), every node type it registers belongs to the pack. ```js LiteGraph.packs.register({ id: "acme-audio", version: "1.2.0", requires: { litegraph: ">=0.10" } }, () => { LiteGraph.registerNodeType("acme/filter", Filter); }); LiteGraph.getNodeDefinition("acme/filter").pack; // {id: "acme-audio", version: "1.2.0"} ``` Settings: `LiteGraph.Packs.Stamp`, `LiteGraph.Packs.AutoReplace`, `LiteGraph.Packs.AllowIncompatible`, `LiteGraph.Packs.Disabled`.
