Class: LGraph

LGraph(o)

LGraph is the class that contain a full graph. We instantiate one and add nodes to it, and then we can run the execution loop. supported callbacks: + onNodeAdded: when a new node is added to the graph + onNodeRemoved: when a node inside this graph is removed + onNodeConnectionChange: some connection has changed in the graph (connected or disconnected)

validateLinks(optionsopt)

Checks that the link table and the slot references agree, and optionally repairs them. The link table (`graph.links`) is the record of a connection; a slot reference is valid only when the link it names connects that exact node and slot. Checks: - a link whose origin/target node or slot does not exist (removed) - a link the target input does not point back to (removed: the input belongs to another link) - a valid link missing from its origin output's `links` (added back) - an input `link` / output `links` entry naming a missing or mismatched link (cleared) - a link `parentId` naming a missing reroute (cleared) Applies only to this graph (not to nested subgraphs). Repairs bypass history and callbacks.
