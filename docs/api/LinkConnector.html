Class: LinkConnector

LinkConnector()

State machine for dragging links on a canvas. idle --startFromOutput/startFromInput--> connecting --dropOnSlot/dropOnNode--> idle idle --moveInputLink/moveOutputLinks--> moving (links detached) --drop--> idle --cancel--> idle (links restored) Moving existing links detaches them when the drag starts; the whole move (detach + reconnect) is one graph transaction, so it is a single undo step, and cancelling reconnects the original links. Design follows the LinkConnector idea in Comfy-Org/litegraph.js (MIT); independent implementation for this runtime's slots and events. Lifecycle: `onEvent(type, detail)` (set by the canvas) receives "link-drag-start" when a drag starts and "link-drag-end" when it ends, with `outcome` "connected", "rejected" (dropped on a node that refused it), "dropped" (on empty space) or "cancelled".
