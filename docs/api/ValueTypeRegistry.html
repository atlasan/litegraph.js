Class: ValueTypeRegistry

ValueTypeRegistry()

Value types: one place that says how a value of a given type is edited, on the canvas and in panels ("widget for type"). LiteGraph.registerValueType("percent", { base: "number", aliases: ["PERCENT"], label: "Percentage", description: "A number from 0 to 100.", examples: ["50", "12.5"], widget: "slider", editor: "slider", options: { min: 0, max: 100, step: 1, unit: "%" }, }); Fields of a definition (all optional): - `base`: a type whose fields are inherited (options are merged, the base's first) - `aliases`: other names (names and aliases are matched without regard to case) - `label`, `description`, `examples`: shown by the panels as the row's help - `widget`: canvas widget type (`LiteGraph.widget_types`); `editor`: panel editor (`LiteGraph.panel_editors`) - `options`: default widget and editor options (a property's own info wins over them) - `default`: value, or a function returning one - `coerce(value, options)`: normalizes a typed or picked value - `validate(value, options)`: null, or a message saying why the value is refused - `format(value, options)`: text shown for the value - `parse(text, options)`: value from typed text Resolution order of the consumers: a registered editor or widget type with the asked name wins, then the value type's `editor` / `widget`. See the panels and widgets plan (agents/plans/2026-11-22-panels-options-node-details.md).
